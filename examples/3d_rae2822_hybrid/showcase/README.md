# RAE2822 mixed-grid showcase

[The LF2 hybrid figure](rae2822_lf2_hybrid.png) fills the archived two-
dimensional triangles and quadrilaterals with the matching extruded wedge/hexa
control-volume averages.  It also shows the true mixed mesh and paints Cp on
the physical airfoil segments.  No scattered interpolation is used.

LF2 contains 12,809 cells: 11,759 wedges and 1,050 hexahedra.  The displayed
CPU development state is not converged and is not an external validation
result.
