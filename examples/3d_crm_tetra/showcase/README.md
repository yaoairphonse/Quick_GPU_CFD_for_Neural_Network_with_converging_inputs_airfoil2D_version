# NASA CRM tetrahedral showcase

[The exact section figure](crm_tetra_exact_section.png) cuts the imported
10,067,380-cell NASA DPW4 body-fitted tetrahedral mesh at y/MAC=2.1027.  Each
colored polygon is the exact intersection between one tetrahedron and the
plane; the lower panel exposes the highly anisotropic boundary-layer cells.
No scattered interpolation is used.

The pressure field is from an unconverged development checkpoint and is shown
to identify the volume mesh that was used by the earlier CRM solver path.
