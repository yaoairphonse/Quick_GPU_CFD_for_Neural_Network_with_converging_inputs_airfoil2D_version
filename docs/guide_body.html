After moving the package, the build command renames and preserves any CMake build directory tied to the old location, then configures a fresh build. It does not depend on a parent project. Absolute paths in historical command.json files record the original invocation.

The output directory must be new or empty. A run invocation builds and directly uses its mesh within one solver process. The mesh command provides an independent geometry preview; a subsequent run rebuilds the mesh because no mesh-cache loader is provided.

2. Point format and geometry processing

x,y
3.605044470E-01,-3.990721966E-02
...

Use the supplied GXXX format: an x,y header, two finite numeric columns, x/c between 0 and 1, one leading-edge point at x=0, paired upper/lower points at each interior x, and at least two distinct vertical trailing-edge points at x=1. Rows need not follow the contour; the original samples may be sorted by y. Filenames such as GXXXX_airfoil_points.csv are optional; validation uses the coordinates.

pipeline/geometry.py pairs identical x coordinates, follows the upper surface from trailing edge to leading edge, follows the lower surface back, and closes the original vertical trailing edge. It preserves all points without smoothing or resampling. Duplicate points, missing pairs, or incompatible formats are rejected. Arbitrary point clouds, repeated NACA closure points, and sharp trailing edges require conversion first; the reader does not infer their topology.

Input coordinates are x/c and y/c. chord_m sets the physical scale: with c=0.5 m, x/c=1 corresponds to 0.5 m. Changing angle of attack rotates the freestream velocity while preserving geometry and mesh coordinates. Patches are 1=upper, 2=lower, 3=vertical trailing edge. Each cut-wall fragment retains its source_edge and patch.

Each run stores the input copy, reordered polygon, patches, and SHA-256 hashes in geometry/.

3. Parameterized meshing: LF1 and LF2

A static Cartesian quadtree starts from rectangular background cells. A cell splits into four children when it satisfies the wall-distance criterion, or intersects a refinement box and remains below its requested level. Neighboring cells are then balanced 2:1. Each physical subface at a coarse/fine interface has one shared flux. The grid remains fixed throughout the solve, with no local subcycling.

3.1 Cut-cell geometry

V_i = ∫_(cell ∩ fluid) dA
x̄_i = (1/V_i) ∫_(cell ∩ fluid) x dA
Cartesian faces retain fluid aperture length A_f and aperture centroid.
Wall fragments retain endpoints, length ℓ_w, normal n_w from fluid into solid, patch, and source_edge.
Geometric closure: Σ_f A_f n_if + Σ_w ℓ_w n_w = 0

Disconnected fluid pieces in one background cell receive separate CVs; connectivity follows actual apertures. A grid line coincident with a vertical trailing edge closes the correct opening and assigns the wall to the fluid side without translating the airfoil.

3.2 Conservative merging of small CVs

A CV with less than half its background-cell area preferentially merges with a connected fluid CV at the same level through its largest positive aperture. Internal faces disappear, wall fragments remain, and volumes and first area moments add. Merging cannot cross solid. Missing valid neighbors cause an error.

V_merge = Σ_i V_i
x̄_merge = (Σ_i V_i x̄_i) / V_merge
Shared internal fluxes cancel: F_f A_f − F_f A_f = 0

The pipeline uses agglomerated finite volumes and actual fluid volumes for CFL control, rather than per-stage state redistribution. Using an enclosing rectangle area in place of V would change the method, so output retains member mappings.

mesh.max_cells caps background refinement. Its default of two million is a protective limit, not a requested count. Larger levels or boxes increase cost; timings for the approximately 4,700/9,500-CV examples do not extrapolate directly.

4. Compressible equations and physical units

4.1 Mean-flow conservation

U = [ρ, ρu, ρv, ρE]ᵀ
∂U/∂t + ∂F_c/∂x + ∂G_c/∂y = ∂F_v/∂x + ∂G_v/∂y
F_c = [ρu, ρu²+p, ρuv, u(ρE+p)]ᵀ
G_c = [ρv, ρuv, ρv²+p, v(ρE+p)]ᵀ
p = (γ−1) [ρE − ½ρ(u²+v²)]
T = p/(ρR), a = √(γp/ρ), Mach = √(u²+v²)/a

The density-based method directly advances conserved variables and recovers pressure and temperature through the equation of state. T∞ and p∞ are static freestream quantities. Angle of attack α sets u∞=Ma∞cosα and v∞=Ma∞sinα; output coordinates do not rotate.

4.2 Newtonian stress and viscous work

μ_eff = μ + μ_t
τ_xx = μ_eff [2u_x − ⅔(u_x+v_y)]
τ_yy = μ_eff [2v_y − ⅔(u_x+v_y)]
τ_xy = μ_eff (u_y+v_x)
F_v = [0, τ_xx, τ_xy, uτ_xx+vτ_xy]ᵀ
G_v = [0, τ_xy, τ_yy, uτ_xy+vτ_yy]ᵀ

Laminar flow uses μ_t=0. SA-neg contributes eddy viscosity to momentum and energy viscous work. Thermal conductivity κ=0: molecular and turbulent Fourier heat fluxes are absent. Temperature still changes through compression, expansion, and viscous work; this is not an isothermal model.

4.3 Sutherland and constant viscosity

μ(T) = μ₀ (T/T₀)^(3/2) (T₀+S)/(T+S)
μ₀=1.716×10⁻⁵ Pa·s, T₀=273.15 K, S=110.4 K

viscosity=sutherland updates viscosity in every cell at every RK stage. constant uses the Sutherland value at T∞ or an explicit constant_mu_Pa_s. Turbulence and viscosity-law switches are independent. Background: NASA Glenn; its temperature convention is Rankine, while this configuration uses kelvin.

4.4 Internal nondimensionalization and SI output

ρ_ref=p∞/(RT∞), a_ref=√(γRT∞), L_ref=c
x*=x/c, ρ*=ρ/ρ_ref, u*=u/a_ref
p*=p/(ρ_ref a_ref²), T*=T/(γT∞), μ*=μ/(ρ_ref a_ref c)
t*=t a_ref/c, dt*=dt_seconds a_ref/c
p∞*=T∞*=1/γ, R*=1
S*=S/(γT∞), μ_ref*=μ∞/(ρ∞a∞c), T_ref*=1/γ

Defaults give a∞≈295.068 m/s, ρ∞≈0.301562731 kg/m³, V∞≈486.862 m/s, q∞≈35740.4355 Pa, and Re_c≈1.033×10⁷. Input coordinates and mesh bounds use chord units. Exported p,T,ρ,u,v,x,y use SI; internal NPY arrays remain nondimensional.

5. Discretization and preassembled operators

5.1 Finite-volume residual

dU_i/dt = L_i(U)
L_i = −(1/V_i) [Σ_f A_f F̂_c(U_L,U_R;n_if) − Σ_f A_f F̂_v + wall integrals]
Each shared face is evaluated once and gathered with opposite signs by its two CVs.

Convection uses piecewise-constant, first-order spatial reconstruction without MUSCL slopes. First order does not make every time step stable. Viscous gradients use preassembled weighted least squares.

5.2 HLLC, the default flux

S_L=min(u_L−a_L,ũ−ã), S_R=max(u_R+a_R,ũ+ã)
S_*=[p_R−p_L+ρ_Lu_L(S_L−u_L)−ρ_Ru_R(S_R−u_R)]
     /[ρ_L(S_L−u_L)−ρ_R(S_R−u_R)]
F̂ = F_L                   if 0 ≤ S_L
     F_L+S_L(U_*L−U_L)     if S_L ≤ 0 ≤ S_*
     F_R+S_R(U_*R−U_R)     if S_* ≤ 0 ≤ S_R
     F_R                   if S_R ≤ 0

Here u_L/u_R are face-normal velocities; tangential momentum is retained. Roe averages estimate wave speeds, without inverting a global matrix. See src/flux.h and the CUDA implementation. Reference: Toro, Spruce, and Speares (1994).

AUSM+-up flux structure
â=(a_L+a_R)/2, M_L=u_L/â, M_R=u_R/â
M_f=M₄⁺(M_L)+M₄⁻(M_R) − pressure-difference correction
p_f=P₅⁺(M_L)p_L+P₅⁻(M_R)p_R − velocity-difference correction
ṁ=â M_f ρ_upwind
F̂=[ṁ,ṁu_upwind+p_f,ṁv_upwind,ṁH_upwind]ᵀ
Kp=.25, Ku=.75, σ_AUSM=1, β=1/8, Mco=1

The complete split polynomials and corrections are in src/flux.h. This published interface retains the compressible baseline Mco=1 and does not expose all-speed low-Mach adjustments.

solver.flux=ausm selects split AUSM+-up mass and pressure fluxes. This option does not enable an implicit method or low-Mach preconditioning. HLLC remains the default and baseline.

5.3 Least squares, CSR, and face-gradient correction

min_g Σ_j w_j [g·(x_j−x_i) − (φ_j−φ_i)]²
M_i=Σ_j w_j d_ij d_ijᵀ
g_i=M_i⁻¹ Σ_j w_j d_ij(φ_j−φ_i)
g_f=½(g_L+g_R)+{[(φ_R−φ_L)−½(g_L+g_R)·d]/|d|²}d

Setup precomputes the 2×2 geometry inverses, weights, neighbor indices, face offsets, wall donors/distances, and true SA wall distances in CSR form, then uploads them. Stages perform coefficient accumulation without rebuilding matrices. Face correction reproduces differences along the centroid displacement.

5.4 SSP-RK3

U¹=Uⁿ+Δt L(Uⁿ)
U²=¾Uⁿ+¼[U¹+Δt L(U¹)]
Uⁿ⁺¹=⅓Uⁿ+⅔[U²+Δt L(U²)]

Each step evaluates three right-hand sides. Spatial accuracy remains limited by first-order convection and wall reconstruction. Reference: Shu and Osher, JCP 77 (1988). RK3 alone does not establish third-order accuracy of the full cut-wall method.

5.5 GPU execution

FP64 structure-of-arrays states remain on the GPU. Shared face fluxes are gathered with cell CSR connectivity; no global sparse-matrix inverse is formed. CUDA Graph batches dispatch 32 sequential time-step trials, rather than 32 independent flow cases. Fused SA combines repeated velocity/SA-gradient, face-wall, and gather traversals; the original agglomerated benchmark reduced graph nodes per trial from 29 to 20. The reference layout remains selectable. The restructuring preserves physics and CFL settings.

The published pipeline adds no implicit method, local time stepping, multigrid, multi-case batching, or shared-memory tiling. Mesh, CUDA event, advance wall, process, and Python export times are reported separately.

6. Walls, angle of attack, and outer boundaries

6.1 No-slip cut wall

u_wall=v_wall=0, ν̃_wall=0, μ_t,wall=0
(∂u/∂n)_wall ≈ (u_wall−u_donor)/d_n
(∂v/∂n)_wall ≈ (v_wall−v_donor)/d_n

Donors must be visible from the fluid side, with d_n≥0.25h by default. If the owner is unsuitable, a valid donor is selected; negative distances are not clipped to small positive values. Wall stress uses molecular viscosity and one-sided normal gradients. Stationary-wall viscous work is zero. With κ=0, there is no isothermal/adiabatic Fourier-wall option; temperature_owner_K is a near-wall sample.

6.2 Characteristic farfield, default on all four sides

λ=[u_n−a,u_n,u_n,u_n+a]
Supersonic inflow, u_n≤−a: prescribe the complete freestream state.
Supersonic outflow, u_n≥a: all characteristics leave; do not impose outlet pressure.
Subsonic flow: combine outgoing interior and incoming freestream acoustic invariants;
select entropy and tangential velocity according to flow direction.

Each face uses its own outward normal. Changing angle of attack changes local inflow/outflow classification; upper and lower boundaries are not fixed inlets or outlets. Mach, angle of attack, and static p/T determine the freestream.

6.3 Optional pressure outlet

Set boundaries.xmax="pressure-outlet" and outlet_pressure_Pa. Subsonic outflow imposes the static pressure while preserving a compatible interior characteristic. Supersonic outflow extrapolates without enforcing that pressure. Backflow uses the freestream reference as a characteristic reservoir. SA inflow uses freestream ν̃; outflow extrapolates it. See src/static_amr2d_boundary.h.

7. One-equation SA-neg model

The fifth conserved quantity is Q=ρν̃. The working variable ν̃ differs from eddy viscosity ν_t. The NASA TMR SA-neg definition includes ft2 and the Note 1c modification, without rotation, roughness, or extra compressibility corrections.

χ=ν̃/ν, f_v1=χ³/(χ³+c_v1³), μ_t=ρν̃ f_v1 for ν̃≥0
ν=μ/ρ, c_v1=7.1, σ=2/3, c_b1=.1355, c_b2=.622, κ_SA=.41
∂Q/∂t+∇·(ρuν̃)=∇·(ρA∇ν̃)+ρ[P−D+(c_b2/σ)|∇ν̃|²]−A∇ρ·∇ν̃
A=(ν+ν̃)/σ on the nonnegative branch
P=c_b1(1−f_t2)S̃ν̃
D=[c_w1 f_w−c_b1 f_t2/κ_SA²](ν̃/d)²
f_t2=1.2 exp(−.5χ²), c_w1=c_b1/κ_SA²+(1+c_b2)/σ

The term −A∇ρ·∇ν̃ follows algebraically from writing the same ν̃ diffusion equation in conservative ρν̃ form; it is not an additional compressibility model. SA convection shares the mean-flow mass flux and upwinds ν̃. Diffusion uses shared face fluxes and corrected gradients.

Closure functions and the negative branch
Ω=|v_x−u_y|, f_v2=1−χ/(1+χ f_v1), S̄=ν̃ f_v2/(κ_SA²d²)
S̃=Ω+S̄                           if S̄≥−.7Ω
  =Ω(−.01Ω−.1S̄)/(−.5Ω−S̄)       otherwise
r=min[ν̃/(S̃κ_SA²d²),10]; use r=10 when S̃=0
g=r+.3(r⁶−r), f_w=g[65/(g⁶+64)]^(1/6)
For negative ν̃: χ=ν̃/ν, f_n=(16+χ³)/(16−χ³)
A=(ν+ν̃ f_n)/σ, μ_t=0
Model source=c_b1(1−1.2)Ων̃+c_w1(ν̃/d)²
Retain the conservative density-gradient and gradient-square terms.

The piecewise S̃ expression is algebraically equivalent to Note 1c and avoids intermediate underflow for tiny Ω. Model bounds on r and the prescribed negative branch are distinct from clipping conserved states or imposing an artificial eddy-viscosity cap.

Negative ν̃ uses the SA-neg source/diffusion extension with μ_t=0; ν̃ is not clipped to zero. Complete branches and closure functions are in src/sa_model.h.

d is the actual shortest distance from a CV centroid to an original polygon segment or endpoint, precomputed once. It differs from the donor-normal distance d_n used for wall stress. Defaults are ν̃∞=3ν∞ and ν̃_wall=0. Model diffusion and source rates constrain automatic time steps.

The implemented coupling is mechanical. Fourier/turbulent heat transfer, wall functions, and NASA flat-plate Cf/profile certification are absent. Re≈10⁷ and h≈c/128 do not establish wall-layer resolution; treat CL/CD/CM as qualitative outputs or version comparisons.

8. CFL, fixed time steps, and convergence

8.1 Automatic global time step

Δt_conv,i=CFL V_i/[Σ_f(|u_n|+a)_f A_f+wall acoustic rate]
Δt_visc,i=viscous_CFL V_i/Σ_f[(4/3)ν_eff/d_f]A_f
Δt_SA,i=SA_CFL/[2Σ_f K_f/(ρ_i V_i)+SA_source_rate_i]
Δt=min_i(Δt_conv,i,Δt_visc,i,Δt_SA,i,time remaining to the current target)

K_f is the shared SA diffusion coefficient times face length divided by distance, including walls. This is explicit global stepping. Defaults: CFL=.15, viscous_CFL=.1, SA_CFL=.1. Set them independently in JSON; --cfl selects automatic CFL control.

8.2 Fixed physical time step

python3 quick_cfd.py run --points examples/G0001_airfoil_points.csv --mode time --stop-time .01 --dt 1e-7
# Equivalent JSON override:
{"solver":{"time_step":{"mode":"fixed","dt_seconds":1e-7}}}

Time steps are entered in seconds and converted to dt*. Fixed dt replaces automatic convective, viscous, and SA limits, shortening only at the target time. Oversized steps can fail positivity. The program does not silently change CFL, clip states, or switch models. --cfl and --dt are mutually exclusive.

8.3 Reaching a time and reaching steady state

--mode time --stop-time 1 advances to t*=1 without a steady-state claim. --physical-time .003 sets a time cap in seconds; the two cap options are mutually exclusive. Defaults are steady mode, t*=100, and a 118-second process budget per grid.

Near-field region Ω: x/c∈[−1,3], y/c∈[−1,1]
R_k=Σ_(i∈Ω)V_i|L_i,k|/Σ_(i∈Ω)V_i ≤ 10⁻³, k=ρ,ρu,ρv,ρE
R_SA/ν̃∞ ≤ 10⁻³
δCL=|CL_now−CL_prev|/max(.1,|CL_now|) ≤ .005
δCD=|CD_now−CD_prev|/max(.01,|CD_now|) ≤ .005
δCM=|CM_now−CM_prev|/max(.01,|CM_now|) ≤ .005

The first diagnostic is at t*=.01, then every .5. For t*≥3, all criteria must pass together for five consecutive checks. Flat CL/CD alone is insufficient. Configurable thresholds are preserved in the resolved configuration and must not be confused with unchanged baseline criteria.

These criteria measure near-field volume-averaged raw RHS and load stability; they do not establish pointwise global residual convergence, grid independence, or experimental accuracy. Exit codes: 0 for completed mesh/time tasks or converged steady flow; 2 for input/numerical/output errors; 3 for an unconverged steady run, with results saved. GPU budgets are checked between batches. A CPU advance call has no hard real-time interruption.

9.2 Surface sampling and markers

Rows represent actual wall fragments and include wall_id, source_edge, owner, donor, patch, normal, and length. All patches are selected by default; upper/lower/trailing-edge selection is available. Coordinates are wall-segment midpoints. p_owner_Pa, rho_owner_kg_m3, and temperature_owner_K sample the neighboring owner CV and are not fully reconstructed wall thermodynamic states. Stationary no-slip wall velocity and Mach are zero. Additional columns include Cp, donor viscosity, d_n, signed shear, and fragment pressure/viscous forces.

9.3 Forces, lift/drag, and Mz

n_w points from fluid into solid
ΔF_pressure=p_w n_w ℓ_w
ΔF_viscous=−τ_w·n_w ℓ_w
F=Σ_w(ΔF_pressure+ΔF_viscous)
D=Fx cosα+Fy sinα
L=−Fx sinα+Fy cosα
Mz=Σ_w[(x_w−x_ref)ΔFy−(y_w−y_ref)ΔFx]
CD=D/(q∞c), CL=L/(q∞c), CMz=Mz/(q∞c²), q∞=½ρ∞V∞²

The flow lies in the xy plane; positive Mz is counterclockwise. No separate nose-up sign convention is applied. The reference defaults to (.25c,0), configurable with solver.moment_reference_xy_c. Two-dimensional forces are N/m span, and moments are N m/m span. Pressure, viscous, and total components each include Fx,Fy,drag,lift,Mz and dimensionless coefficients; JSON also contains patch contributions.

Whole-airfoil loads always include all original wall fragments, independent of field ROI or surface selection. Absolute static pressure is used; its constant contribution cancels for a closed body, but not for individual patches. Signed shear follows the fluid-stress tangent convention; body viscous force uses the reaction, so integrate force columns directly.

mesh_setup includes polygon input, cut-cell/AMR construction, merging, geometry checks, and fixed tables, excluding GPU setup and solving. CUDA event time sums elapsed trial-batch stream intervals and can include dispatch gaps. Advance wall time includes control and waiting. Process time covers all C++ setup, monitoring, and output. After re-export, pipeline.json retains the original calculation. export.config.json and export.history.json describe current output options and export history without changing the solution.

LF1 and LF2 use different fixed refinement rules. Their visual comparison shows the effect of resolution; it does not establish grid independence.

Surface Cp uses owner-cell pressure and is plotted at wall-fragment midpoints. Upper/lower patches are shown separately. The axis is inverted according to the usual pressure-coefficient plotting convention. Fine geometric fragments may share an owner CV and pressure value.

Rendering assigns each agglomerated CV average to its background member rectangles, then masks the solid airfoil. It does not reconstruct exact cut polygons or interpolate a smoother solution. The compact plotting input and provenance are retained in docs/data/; regenerate figures with python3 docs/plot_flow_gallery.py after installing docs/requirements.txt.

11. Configuration editor

The complete package defaults appear below. Edit and download the JSON, then load it with --config airfoil_config.json. Partial overrides are also accepted; unknown keys cause errors. This offline page edits configuration only; it does not run the solver in the browser.

Edit refinement boxes directly in JSON. Reducing a profile's maximum levels also requires box.level values at or below that limit. The Python entry point performs full parameter validation; the download button only checks JSON syntax.

Development status: 3D and low-Mach preconditioning

The published pipeline is two-dimensional and has no low-Mach preconditioning switch. A separate local development effort is implementing steady low-Mach preconditioning and a viscous, one-equation Spalart–Allmaras 3D sphere case. Those changes are not included in this English documentation update. See development notes.

Planned low-speed checks cover M=.1/.01/.001, pseudo-time and flux/boundary consistency, cut cells, viscosity, SA, and CPU/CUDA agreement while preserving the LF1/LF2 high-speed regressions. Real unsteady flow requires the correct physical-time equation; steady pseudo-time must not be reported as physical time.

Heat transfer remains a later task: Fourier fluxes, Pr/Prt, and thermal-wall conditions. Solid conduction also requires an energy equation and interface coupling. The published mechanical model retains κ=0.

The core was copied from a validated standalone snapshot. CORE_PROVENANCE.json retains the extraction hashes and the current English-source hashes. Records: 20 comparisons, audit and measured timing, parameter controls. Large raw runs and archived binaries remain local.

Original preregistered comparison thresholds: relative field L1≤2e-11, Linf≤2e-10, relative SA Linf≤2e-10, and identical steps, times, and rejected-step counts. SI EOS and wall-load integration are checked separately.
